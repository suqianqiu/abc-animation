# 核心页面图册

[返回产品首页](../README.md) · [操作手册](USER_GUIDE.md)

新增章节为0.1.75–0.1.76实机画面，其余沿用0.1.74演示画面；各节标注版本。示例节目只用于介绍页面操作，不表示内容授权、官方合作或默认推荐；实际显示以设备配置及版本为准。

[查看家长管控功能示意海报](PARENTAL_CONTROLS.md#功能点示意海报)；海报插画与下面的真实截图分开提供。
