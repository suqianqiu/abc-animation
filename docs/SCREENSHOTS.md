# 核心页面图册

[返回产品首页](../README.md) · [操作手册](USER_GUIDE.md)

以下均为 **0.1.71 实际运行画面**，使用演示档案、播放记录和本地内容状态。示例节目只用于介绍页面操作，不表示内容授权、官方合作或默认推荐；实际显示以设备配置及版本为准。
