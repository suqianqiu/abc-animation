# 产品目标与用途

[返回产品首页](../README.md) · [阅读操作手册](USER_GUIDE.md)

## 产品定位

ABC动画是一款面向 Android TV 的家庭动画管理与观看应用。它以英语启蒙和亲子陪伴为主要方向，也保留中文及少/无对白内容供家长选择，让选片、下载、观看和时间管理尽量在清晰的流程中完成。

## 产品目标

| 目标 | 对使用者的价值 |
| --- | --- |
| 更容易选到合适内容 | 结合年龄、英语基础和兴趣浏览节目，减少查找负担。 |
| 更适合电视与遥控器 | 使用海报、清晰焦点与简单的方向键操作，让孩子和家长容易辨认当前位置。 |
| 更方便继续观看 | 保留最近播放与进度，按日期整理历史，减少重复寻找。 |
| 更清楚地管理时间 | 由家长设定每日额度，选择计时范围和倒计时显示。 |
| 更清晰地约定续看规则 | 到时先暂停，按家长设定的题目与通过门槛，获得有限的当日续看时间。 |
| 更方便整理本地内容 | 集中查看下载任务与已下载文件，支持批量操作和空间整理。 |

## 适合谁

- 希望在电视上安排英语动画或亲子观看内容的家庭。
- 希望统一管理下载、播放历史及每日观看安排的家长。
- 对家庭电视产品体验感兴趣的个人学习者与交流者。

**2岁半之前不建议观看动画。** 年龄与英语阶段标签是选片提示，不是专业评级。家长应结合孩子的实际情况决定是否观看以及观看什么。

## 典型用途

### 家长先选片，孩子再观看

家长先完善档案、检查节目显示与每日时长（小时／分钟拨盘），再把准备观看的内容加入“我的片单”。孩子进入首页后，可以从海报中找到已选内容。

### 预先准备内容

在网络和设备空间允许时，提前下载有合法使用权限的内容。下载完成后从本地播放，观看安排不必依赖临时下载完成。

### 继续上次观看

在“历史”中找到最近看过的节目，查看最近播放时间和进度，然后继续观看。每个节目只保留最近一次展示，避免同一节目铺满多天的列表。

### 提醒观看节奏

家长设置每日可用时长，选择只计算实际播放时间，或将本应用内的操作与解锁时间一起计入。需要时打开顶部倒计时，帮助了解剩余时间。

### 约定到时后的续看

由家长选择是否开启答题续看，按孩子实际水平选择题库和科目。例如设置“3题答对2题，续看10分钟，每日最多2次”，并约定未通过时先休息。内置题目、答案与文字解析可离线查看，随机与错题加权可分别选择。

答题期间暂停计时；通过后保留原有已用时间，只增加当日额度，继续观看时按原来的计时范围计算。答题通过不会开放家长设置权限。

完整规则与示例见[家长管控功能说明](PARENTAL_CONTROLS.md)。

## 产品不作出的承诺

- 不承诺提升英语成绩、达到特定语言水平或产生特定学习效果。
- 不替代教学、家长陪伴、健康管理或专业建议。
- 不承诺任何第三方内容持续可用，也不承诺所有电视、音轨和字幕格式都完全兼容。
- 不为第三方作品或内容提供方作官方推荐、授权背书或商业推广。

本项目用于个人学习、产品交流和家庭场景探索，不以营利为目的。请仅在具备合法内容使用权限的前提下使用，并阅读[使用声明与免责声明](NOTICE.md)。

## 版本更新

每天打开时后台检查正式新版本；家长可手动检查、暂停或继续下载，按引导开启安装授权，再由系统确认覆盖升级。现有登录、设置与下载内容保留。
