# ABC动画 v0.1.78

升级检测和安装包下载优先使用腾讯云香港COS，GitHub保留为备用，解决电视直连GitHub不稳定导致下载失败的问题。

## 本版更新

- 每日首次打开与手动检查均优先从腾讯云取得版本信息，网络或数据异常时自动尝试GitHub。
- 安装包优先从腾讯云下载，中断后保留进度并自动重试；腾讯云不可用时继续尝试GitHub附件API及原下载地址。
- 保留HTTPS证书和域名验证，以及安装包SHA-256、包名、签名、版本与CPU架构校验；不在应用中放入云密钥。
- 显示下载来源、重试状态和更明确的网络错误，保留0.1.77旧系统证书兼容及原有界面优化。

## 升级与验证

旧版升级模块没有腾讯云地址，需要先覆盖安装一次本版或本次本地兼容测试包；不要卸载或清除数据。随后可在“设置 → 家长设置 → 版本更新”进行升级。

微鲸Android 5/API21已用本版生产升级代码完成腾讯云版本检查、完整APK下载及校验；故障模拟覆盖腾讯云优先、GitHub备用、中途断开续传、暂停、错误分片和异常内容拒绝。没有安装QA应用。系统升级安装保留给用户手动验证，不能视作整个手动升级流程已经通过。

# ABC动画 v0.1.77

修复微鲸Android 5.0检测更新失败：补齐升级连接缺少的官方Sectigo根证书，保留证书链和域名校验，不关闭HTTPS验证。

## 本版更新

- 修复升级模块在旧系统上出现“找不到受信任证书根”、无法检查GitHub新版本的问题。
- 更新专用证书包只接受三份固定SHA-256指纹的官方根证书；保留系统及原有证书，不修改电视系统信任库。
- 区分证书校验失败、域名解析失败及连接超时提示，便于判断网络问题。
- 继续保留0.1.76焦点行居中、低版本连续滚动、家长设置图标网格及弹窗优化。

## 旧电视怎么升级

原版0.1.74–0.1.76如果已因缺证书而无法检查更新，不能依靠坏掉的检查连接自动取得本修复。请先从电脑下载本版，再通过U盘或ADB覆盖安装一次；随后再使用应用内更新。不要为升级卸载或清除数据。

补齐证书不等于保证所有国内网络可达。不同网络仍可能超时，当前仍以GitHub为更新源，没有国内备用下载源。

## 验证范围

微鲸Android 5/API21原有连接复现SSLHandshakeException；修复后的同机原生网络诊断取得版本信息HTTP 200、附件跳转HTTP 302、APK分片HTTP 206。沿用严格证书校验，未安装QA应用、未替用户触发下载或升级。拒绝未知/空证书包检查通过。电视版与通用版代码、资源、资产一致；兼容测试包与本版除版本清单外内容一致。

这是版本检测和APK分片连通性验证，不等于完整电视自升级已经通过；完整手动升级由用户继续验证。

# ABC动画 v0.1.76

本版合并0.1.75弹窗优化，以及0.1.76首页滚动与家长设置调整。

## 本版更新

- 首页焦点海报所在行居中显示，首尾按内容边界停住；快速连按跟随最新焦点。
- 修复微鲸Android 5关闭系统动画时的跳切：应用内部按帧滚动，不修改电视全局动画设置。
- 家长设置统一为3×3等尺寸图标按钮，16dp间距，整页无需滚动。
- 确认/取消按钮至少120×48dp；长文案和列表在内部滚动，操作区固定。删除和放弃默认聚焦取消。
- 补齐旧系统图标解析兼容；继续保留每日更新检测、家长密码、观看时长和下载管理。

## 验证与升级

最终电视包已覆盖安装到微鲸Android 5/API21和AM9 Pro/API34，两台各56项检查通过；微鲸系统动画缩放保持0，实际记录到多个滚动中间位置。弹窗优化此前在两台各完成108项检查。通用版与电视版代码、资源和资产逐项一致，原生播放器库保持不变；通用版本轮没有独立完整UI回归。华为旧地址本轮无法连接，未计入实机通过。

下载电视版或通用版覆盖安装，保留设置、登录与已下载内容。0.1.74起也可在“设置 → 家长设置 → 版本更新”中检查升级。临时QA测试工具不包含在发布附件中，已从两台实机卸载。
