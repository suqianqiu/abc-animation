# 升级检测与安装包下载

## 0.1.78开始的主备机制

每日首次打开及手动检查优先请求腾讯云香港COS：

`https://www.dajinsuan.com/tvapp/abc-animation/latest.json`

腾讯云网络不可用、响应异常或版本信息无效时，自动尝试GitHub正式Release。版本JSON不缓存，安装包使用固定版本路径。下载依次尝试腾讯云（含一次重试）、GitHub附件API、GitHub原附件地址，次数有限。中断保留已经收到的数据；跨源继续下载使用相同版本、文件长度和SHA-256，最终必须通过包名、签名、版本及CPU架构校验。

版本文件和APK允许匿名读取；应用不含腾讯云密钥。只使用固定香港存储桶和本项目GitHub地址，HTTPS证书链、域名验证保持开启。不代表任何网络下都保证可达；两端都不可用时显示原因并保留进度。

## 老版本如何获得修复

旧版程序没有腾讯云地址，不能仅靠更新云端文件改变它的请求方式。请从产品首页下载新版，通过电视支持的U盘或ADB覆盖安装一次，保留数据；以后再使用“设置 → 家长设置 → 版本更新”。不需要卸载、清数据或导入系统CA。

本次用户手测使用本地0.1.76兼容测试包作为起点，已包含0.1.78相同的升级代码；它不是GitHub历史0.1.76附件，不会替换历史发布。用户可从测试包手动升级至正式0.1.78。

## 微鲸验证范围

- Android 5/API21：运行正式APK内的升级代码，腾讯云检查成功，完整下载电视APK并验证SHA-256及安装包身份。
- 故障模拟：腾讯云检查及下载优先、检查失败回退GitHub、下载备用链路、断线自动续传、正确Range、错误Range拒绝、JSON拒绝、忽略Range时安全重下、暂停后不自动重试。
- 电视版和通用版代码、资源一致；本地测试包与正式电视版仅版本清单和签名数据不同；签名验证通过。
- 未安装QA应用，未替用户触发系统升级。完整手动安装及重启仍需用户确认测试结果。
